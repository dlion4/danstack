When to use which?

Warning Modal (Before Action): User clicks "Pay / Send / Create VA / Submit Bulk". Before calling API, show warning modal with permission checkbox (I understand risk). Example: AP-002 needs 2 approvers, BULK-003 limit exceeded, VA-001 limit reached. No money moved yet, can cancel 100% safe.

Error Full-Page (After Failure): User already confirmed, saw spinner "Processing 2-4s", then API returns error. Navigate to full-page error (like our 38 pages) or show error modal with retry. Shows trace ID + vault safe + no double charge. Example: TR-001 insufficient float — user sent, waited, failed.
